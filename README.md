## 📖 Sobre o projeto

O **HillAplicado** é um projeto desenvolvido em Java que explora os fundamentos matemáticos da **Cifra de Hill**, utilizando álgebra linear, matrizes e aritmética modular para realizar operações de cifragem e decifragem de mensagens.

Sua implementação segue os princípios da **Programação Orientada a Objetos (POO)**, priorizando organização, encapsulamento e reutilização de componentes.

O projeto utiliza conceitos e componentes desenvolvidos durante os estudos do **J126**, mantendo uma arquitetura independente e simplificada.

---

## ⚙️ Características

- 🔑 Cifragem e decifragem de mensagens
- 🧮 Operações matriciais e aritmética modular
- 🧩 Componentes reutilizáveis e orientados a objetos
- ☕ Implementação em Java
- 📚 Finalidade experimental e educacional

| Tecnologia | Aplicação |

| **Aritmética Modular** | Transformações numéricas |

## 🎯 Objetivo

Demonstrar a aplicação prática de conceitos matemáticos na construção de componentes de software, valorizando a simplicidade, a modularidade e a reutilização de código.

---

## 🔒 Observação de segurança

> Este projeto possui finalidade educacional e experimental. A Cifra de Hill clássica não é considerada segura para proteger informações sensíveis.
